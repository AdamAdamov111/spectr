# Открытые данные стенда SPECTR (пакет «Нефтегаз и трубопроводный транспорт»)

Все файлы в этом каталоге генерируются скриптом `ui/scripts/ingest-open-data.py` (дата выгрузки 2026-09-16).
Объекты, собранные из этих источников, помечены источником `open_ref` / `jodi` / `eia` / `volve` в карточке и в Explain;
всё остальное на стенде (контрагенты, договоры, закупки, заявки ТОиР, инциденты, датчики, сотрудники) — синтетика с маркировкой `SYNTHETIC`.

Ограничения честности: добыча по JODI для России обрывается в марте 2023 года (Россия перестала передавать данные); для текущей оценки используется ряд EIA STEO. Скважины Volve — норвежские, на карту России не наносятся и подписаны как эталонный набор. Состояние НПС (давление, режим, аномалии) и загрузка НПЗ — синтетика.
